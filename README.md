# Learning Library - Content Curation

This repository is the shared workspace of the content operations team.

- `pipeline/candidates.json` - candidates submitted for the current curation cycle
- `policy/editorial_policy.md` - the currently active curation policy
- `pipeline/queue_status.json` - the working status of each candidate
- `pipeline/rejected.json` - the list of rejected candidates with reasons
- `reports/` - published decision reports

Operations staff update the queue status, publish reports and open review work items through the
repository tools. Do not edit the policy during a curation cycle.
